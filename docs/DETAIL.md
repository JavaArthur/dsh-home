# Home · 个人工作台

Home 是一个 DSH 的首页工作台插件：把待办、专注计时、Flomo 笔记时间流、常用快捷入口和壁纸放在同一页，作为日常的起点。侧栏与首页工作台区都会出现 **Home** 入口。

## 功能

- **待办**：添加、分类、勾选完成、编辑、删除，可关联到专注计时。
- **专注计时**：番茄钟，支持专注/休息、暂停、继续、重置；按绝对截止时间结算，不随 tick 累积。每日目标与专注历史统计。
- **Flomo 笔记时间流**：按日期倒序读取、搜索、按标签筛选、展开全文和打开原文；"记一笔"可直接写入 Flomo。Flomo 是笔记的唯一来源，本地仅保存未提交草稿与防重复提交回执。
- **快捷入口**：站点 Logo、分类筛选、拖动排序，内置 Google / Bing / 百度搜索。
- **壁纸**：内置海岸/森林/暮色/极光预设，自选 HTTPS 图片或上传本地图片，支持遮罩与自动轮换。
- **主题与自适应**：跟随 DSH 深浅色与中英文，窄屏折叠为单列；颜色使用宿主主题变量。

## 配置

插件的非敏感配置在 DSH **插件** 页面（Home 条目）中设置：

- `flomo.enabled`：是否启用 Flomo 笔记功能。关闭后隐藏笔记入口，不注册笔记服务。
- `flomo.endpoint`：Flomo MCP 地址，默认 `https://flomoapp.com/mcp`。

Flomo 访问令牌属于密钥，不写入配置：打开首页 Home 的"记一笔 / 笔记时间流"页面，在连接框输入令牌，令牌由 DSH 凭据服务安全保存（引用名 `DSH_HOME_FLOMO_TOKEN`），每次操作重新解析，不会出现在页面、配置或工具返回中。

## 使用

安装后在侧栏选择 **Home**，或在首页工作台打开。顶部的"首页设置"可调整称呼、专注/休息时长、每日目标与搜索引擎；"换背景""调整布局"分别管理壁纸与卡片顺序。

## 限制

- Flomo 搜索单次最多返回 50 条且按天分页，单日记录过多时页面会提示用关键词或标签缩小范围，不声称读到全部。
- 计时在页面未打开时不保证即时系统提醒，也不会自动开始下一轮。
- 在线图片源（Lorem Picsum / Unsplash 精选）与外部图片网址的长期可用性不由本插件保证。
- 本插件不读取或迁移其他插件的数据，仅使用自己的存储域。
